# Warren A. Jones — Personal Wiki Site

This repository contains the source files for my personal website, [warrenajones.com](https://warrenajones.com), a wiki-style public archive for my professional work, writing, projects, and practitioner-scholar interests.

The site is designed to function less like a traditional portfolio landing page and more like a personal knowledge base. It organizes my background, career interests, selected initiatives, technical projects, writing agenda, and professional point of view in a format inspired by public wiki articles.

## Purpose

This site serves as a central place to document and share:

- My professional background in nonprofit operations, governance, and organizational systems
- Selected career initiatives and major bodies of work
- Data analytics, business intelligence, and applied machine learning projects
- Writing, white papers, research notes, and commentary
- Practitioner-scholar interests related to nonprofit infrastructure, AI/ML, decision-making, and operational capacity

The larger goal is to create a durable public archive that reflects the scope of my work across operations, data, technology, and mission-driven organizations.

## Built With

This site is intentionally simple and lightweight.

- HTML
- CSS
- GitHub Pages
- Custom domain through GoDaddy

No frameworks are currently used. The site is static by design so it can remain easy to maintain, expand, and version over time.
